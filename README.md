# Birdie Squad Golf Club Website

## Project Overview

This is the Phase 1 public website for Birdie Squad Golf Club — a public-benefit organisation that uses golf as a platform for entrepreneurship development, mentorship, networking, leadership, and community upliftment.

## Website Structure

```
├── index.html          # Homepage
├── about.html          # About Us page
├── programmes.html    # Programmes overview
├── sponsors.html      # Sponsors & Partners (sponsorship prospectus)
├── governance.html    # Governance & Impact
├── contact.html       # Contact page
├── get-involved.html  # Get Involved page
├── css/
│   └── style.css      # Main stylesheet
├── js/
│   └── main.js        # JavaScript functionality
└── images/
    ├── logo.svg       # Logo (primary)
    └── favicon.svg    # Favicon/secondary mark
```

## Brand Guidelines

| Colour | Hex | Usage |

### Typography

- **Primary Font:** Manrope (Google Fonts)
- **Secondary Font:** Inter (Google Fonts)

- **Body:** Manrope Regular (400) / Inter

### Tagline

**"Driving Opportunity Through Golf"**

### Brand Positioning

Birdie Squad is positioned as:
> A community-rooted, impact-driven organisation that uses golf as a platform for entrepreneurship, mentorship, leadership, networking, and opportunity creation.

### Brand Pillars

1. **Impact** — Golf is used to open doors, not close them
2. **Opportunity** — We connect people to growth, exposure, and support
3. **Leadership** — We develop discipline, confidence, and social capital
4. **Community** — We serve broader groups, not an exclusive private circle
5. **Partnership** — Sponsors and stakeholders are integral to our impact model

### What Makes Us Different

- Public-benefit focus (not a private golf club)
- Entrepreneurship platform (golf is the vehicle, business development is the product)
- Sponsor-ready governance (accountability for CSI/CSR funders)

## Website Features

### Phase 1 Pages (Launch)

1. **Home** — Hero section, impact pillars, programme preview, social proof, CTAs
2. **About Us** — Mission, vision, brand pillars, what sets us apart
3. **Programmes** — Youth Golf & Leadership, Entrepreneurship Accelerator, Mentorship Network, Community Upliftment
4. **Sponsors & Partners** — Tiered sponsorship packages (Title, Strategic, Community, In-Kind)
5. **Governance** — Organisational status, leadership, endorsements, impact metrics
6. **Contact** — Contact form, contact information, quick links
7. **Get Involved** — Pathways for participants, mentors, volunteers, community partners

## Design Direction

### Visual Style

- Clean, modern, community-focused
- Strong white space
- Large, confident headings
- Premium but not elite
- Green-led interface with gold highlights

### What to Avoid

- Sporty design language (aggressive motion, sports typography)
- Exclusive imagery (private club settings)
- Golf-centric iconography throughout
- Overly corporate design

### Mobile-First Priorities

- Fast load times (WebP images, lazy loading)
- Vertical scrolling layouts
- Large tap targets (48px minimum)
- Readable text (16px minimum body)

## Technical Notes

- Uses Google Fonts (Manrope, Inter)
- CSS custom properties for theming
- Vanilla JavaScript (no frameworks)
- SVG logos for scalability
- Responsive grid layouts
